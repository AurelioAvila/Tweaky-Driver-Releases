# Security policy

Tweaky Driver is proprietary software. Public installers and release notes are distributed from [Tweaky-Driver-Releases](https://github.com/AurelioAvila/Tweaky-Driver-Releases/releases). Application source code is private.

## Report a vulnerability privately

Use [Report a vulnerability](https://github.com/AurelioAvila/Tweaky-Driver-Releases/security/advisories/new) to send a confidential report to the maintainers. Please do not post vulnerability details, credentials or personal information in a public issue.

Include the affected app version, Windows version, reproducible steps, expected and observed behavior, and the potential impact. Use synthetic accounts and redact tokens, email addresses, device identifiers and payment information from evidence. Do not send private signing keys or passwords.

Test only systems and accounts you own or are authorized to assess. Do not interrupt other customers, access their data, install drivers on someone else's computer, or perform load tests against production services. No paid bounty or response-time guarantee is offered by this policy.

## Versions and updates

Reports should identify the exact installed version and, when relevant, the installer SHA-256 from its release notes. Check the latest release for updates and known limitations. Updating the account service does not update an installed desktop application.

Distributed Windows executables and installers must have a valid Aurelio Avila publisher signature and trusted timestamp. Download installers from the official release page. Signing establishes publisher identity and file integrity; it does not guarantee that software has no vulnerabilities or that Windows SmartScreen will never display a prompt.
